# 433｜資產再配置版本入口

以實際持倉、本次目標與交易限制，產生可核對的台股股票與 ETF 再平衡方案。歷史專案名稱保留為 433，不預設 40／30／30、4312 或其他固定權重。

本工具暫時僅適用台股投資人，以新臺幣試算台灣市場股票與 ETF 再配置。包含在台掛牌、追蹤海外資產的 ETF（例如 00662）；不適用直接交易海外股票、外幣交易或期貨契約。V4 可依已核對的普通股及新臺幣 ETF 商品帶入費率；債券 ETF、外幣加掛及其他特殊商品須另行核對，不把所有 ETF 視為同一稅別。

## 原始版使用方式

1. 填現金餘額與 T+2 交割款：正數應收、負數應付。交割款指尚未反映於現金餘額的金額；完成交割後更新餘額並清除對應款項，避免重複計算。
2. 新增實際持倉、股數與試算價格。自行確認哪些標的是「台股正二」，監測清單不代表持倉。
3. 所有目標留白時只檢查現況；需要調整時，完整填寫各標的與現金目標，合計須為 100%。現金下限至少 10%，可以提高；現金目標可高於下限。
4. 比較完整再平衡、僅用新增資金、容許區間調整。交易限制可選允許買賣、不能賣但可買、完全不動。
5. 檢查股數、費用、剩餘現金與偏差，匯出方案。工具不連接券商、不下單。
6. 「套用估計方案供核對」會先保存原始快照，更新估計股數及交割款，並把投入／提領歸零。實際成交後須自行核對成交價格、股數與現金差額；此操作不是成交紀錄或成交確認。

首次開啟不帶入推定持倉。示範資料明確標示且需要確認載入。

## 計算口徑

- 目前總資產 = 各標的股數 × 試算價格 + 現金 + 有正負號的交割款。
- 本次資產基準 = 目前總資產 + 投入／提領（正投負提）。
- 調後總資產 = 本次資產基準 − 預估交易成本。
- 現金比率 = 調後淨現金 ÷ 調後總資產。這是 T+2 交割後淨額，不是盤中可下單額度；工具不模擬各日券商交割時序。
- 費率選項：未折扣手續費 0.1425%（買賣皆收），最低手續費預設 0 元；證交稅僅賣出收取，一般股票 0.3%、股票型 ETF（含 00662、台股正二）0.1%。新增標的預設一般股票；ETF 可一鍵套用對應費率。既有保存／匯入的自訂費率保留，亦可透過按鈕重設。未套用股票當沖優惠或其他商品減免。
- 費用每標的視為一筆委託：`max(最低手續費, 成交金額 × 手續費率) + 賣出金額 × 交易稅率`，估計至分。請按商品與券商修改費率、最低費用與交易單位；實際券商進位、折扣與分筆成交可能不同。
- 1 股表示零股、1000 股表示整張。剩餘零股不會因整張設定被強制出售。
- 完整模式先賣超額，再按目標金額缺口由大到小買入，保留以費用前資產計算的現金目標，因此費用後通常有少量保守緩衝。
- 僅投入模式不賣出，買進加費用不超過本次正投入；既有現金不足下限時優先保留現金。
- 區間模式只調整超出容許偏差者，向區間邊界靠攏。這是可解釋的啟發式方法，不保證全域最少交易、最佳化解或每個可行目標均能達成。
- 未達現金下限、未持有 00662／台股正二、未達目標時會列出缺口，不宣稱配置已完成。限制衝突不會偷偷解除鎖定。

## 保存與備份

持倉與最多 50 份快照保存在此網站來源的 localStorage；不上傳持倉。來源、網域或瀏覽器改變時不會自動同步，清除瀏覽器資料也會清除紀錄。請定期匯出 JSON 備份。

只有完整且通過驗證的輸入會自動保存。編輯中缺欄、錯誤目標等暫存狀態不會覆蓋上次有效資料。舊版沒有持久化資料，沒有自動匯入舊頁狀態。

- JSON 包含全部設定與快照；匯入需先確認覆蓋。市場觀察筆記區塊已移除；舊版備份中的筆記仍保留於備份資料，不在介面呈現，以維持相容性並避免意外遺失舊資料。
- CSV 只匯入／匯出持倉，欄位順序見匯出的空白範本；現金與交割款不受 CSV 覆蓋。代號使用文字，請留意試算表不要移除前導零。
- 來源網址只允許 HTTP(S)。CSV 匯出會防止文字欄位被視為試算表公式。
- 讀到損壞或未知版本的本機資料時，停止自動覆蓋並提供原始資料下載。
- 快照資產差額包含現金流與行情變化，不能稱為投資報酬。

## 情境試算

情境試算採各 ETF 自身的假設漲跌幅，基於目前持倉、不含本次投入／交易／成本；不把多日指數報酬乘二當作正二長期報酬。

目前沒有串接即時行情、排程晨晚報或券商。

### 查找與費率操作

1. 「標的代號」及「標的全稱」都可查找，另保留官方交易簡稱。代號精確匹配或名稱精確且唯一匹配才會帶入；部分名稱及同名結果必須選取候選，不自動採用第一筆。保留前導零及代號字尾，中文輸入法組字期間不自動選取。
2. 選取新標的會一起更新代號、全稱、簡稱及商品資訊。編輯識別欄位時清除舊配對資訊，避免新代號搭配舊名稱；不改動股數、價格或配置角色。
3. 新增標的首次從有效名錄選定已核對商品時可帶入預設費率。修改手續費、最低費用或證交稅後，改為「手動設定」；再次查找保留原值。只有明確按下「套用此商品預設」才重設手動費率。
4. `Asset.kind` 的「核心／台股正二／其他」是使用者設定的配置角色；`securityType` 才是商品分類。兩者分開，不因代號或名稱擅自改動配置原則。
5. 名錄載入失敗可重試或手動輸入。資料超過 45 天或日期異常時停止自動套用；已有自動費率的持倉須重新核對有效名錄，或明確改成手動後才提供試算。保存、備份與手動輸入仍可使用。網路載入設有逾時，不因等待名錄而無限卡住。
6. 原名稱、來源日期與費率保存在持倉和快照內；名錄更新不回寫歷史快照，也不自動修改既有持倉。若目前名錄與原自動設定的商品身分或規則不符，要求使用者核對。

### 商品費率及主要限制

買賣手續費預設 0.1425%，最低手續費預設 0 元；這是工具設定，不是每家券商統一實收費率。證交稅只計賣出，再配置不自動套用股票當沖優惠。

| V4 商品分類                                       | 自動費率條件                                     |   預設賣出證交稅 |
| ------------------------------------------------- | ------------------------------------------------ | ---------------: |
| `stock` 普通股                                    | 官方公司資料與普通股編碼一致                     |             0.3% |
| `equityETF` 股票型 ETF                            | 官方基金類型及新臺幣商品編碼一致                 |             0.1% |
| `otherETF` 其他已核對 ETF                         | 包含已核對的新臺幣槓桿／反向、期貨、平衡型等 ETF |             0.1% |
| `bondETF` 債券 ETF                                | 不提供自動費率，保留原值供手動核對               |         手動設定 |
| `unsupported` 特殊商品、TDR、外幣加掛或未確認類型 | 不提供自動費率；外幣商品亦超出工具交易幣別範圍   | 手動核對或不適用 |

分類同時使用官方 CSV 基金類型與已核對的證券編碼規則，未識別的新類型不繼承相似名稱的分類。不能只看 `00` 開頭、`B`／`L`／`R`／`D` 字尾或名稱包含「美元」「債」判斷交易幣別或稅率。公司資料中的 TDR 也不能直接當成普通股。

符合現行條件的原型被動債券 ETF 暫停徵收證交稅至 2026-12-31；槓桿與反向債券 ETF 不適用。主動債券 ETF 不能直接套用該停徵。V4 不替債券 ETF 猜測免稅資格，需手動核對稅率與期限。財政部 2026-10-01 公告仍是延長停徵及納入主動債券 ETF 的修正草案，不能當成已生效規則。

### 名錄更新流程

`.github/workflows/update-catalog.yml` 每週一 UTC 02:23（臺北 10:23）排程檢查，也可手動執行。GitHub 排程可能延遲。流程以唯讀儲存庫權限下載官方資料，核對 HTTPS 來源、大小、欄位、日期、重複代號、最低筆數、名稱與分類，產出 `official-twse-catalog` 候選 artifact，保留 30 天。

排程成功只表示取得待審查候選，不會自動更新正式名錄、網站、持倉或快照。維護者需下載候選，檢查 `inspection.json`、資料日期、筆數與分類差異，將合格 `twse-securities.json` 放入 `public/data/`，執行測試後以 PR 發布。下載或校驗失敗時保留既有正式檔，不部署空檔或部分結果。若長時間未審查發布，45 天後前端會停止自動費率；手動方式仍可使用。

```sh
python -m unittest discover -s tests -p catalog_pipeline_test.py
python scripts/update-catalog.py --output-dir test-results/catalog
```

此架構不需要外部資料庫、付費 API 或部署新服務商。工作流程仍使用 GitHub Actions；執行額度、artifact 保存及 Pages 限制依 GitHub 帳戶與服務政策，不另承諾永久免費或無配額。

### 保存相容與驗證

V4 使用 `433.portfolio.v4`，不自動搬移、覆寫或刪除 V1–V3 的資料。JSON 備份結構升為版本 3；仍可讀取舊結構 1／2，將目前持倉、快照、試算來源及套用前持倉標示為手動費率並保留原數值。V4 格式需由 V4 讀取；不要拿新版 JSON 覆蓋舊版本資料。

CSV 接受舊十欄、十二欄及 4.1.0 的十八欄格式，匯入後一律為手動費率。CSV 不攜帶可自動信任的名錄身分或費率規則；保留現金與快照，匯出名稱有試算表公式字首防護，含引號、逗號及欄位內換行可往返。JSON 保留完整快照與商品資訊，仍是主要備份格式。V4 以精簡 JSON 匯出，匯入上限為 32 MiB；CSV 仍為 8 MB。新增快照與套用估計方案前會檢查包含交換格式說明的完整候選備份大小，超限不新增、不改持倉；匯出也會檢查上限，不產生超過自身讀取能力的備份。這不代表瀏覽器可保存 32 MiB，localStorage 額度通常較小；保存失敗時仍可在上限內匯出。

驗證項目包含名錄解析與錯誤回退、唯一／歧義匹配、00662 與正二／一般股票／債券及特殊商品、前導零、中文輸入、快速輸入、手動費率保留、舊備份遷移、快照不變，以及 100 標的／50 份快照的保存與匯出。瀏覽器測試另獨立核對費用、JSON／CSV 往返、真實容量不足與恢復、跨分頁衝突、320／390／768 像素排版，並確認搜尋不傳送持倉或查詢文字。完成結果以建置紀錄及 CI 報告為準。

## V4 4.1.0 財務資料交換

預設 JSON 現在包含 `financeFormat`：格式識別、版本、TWD、股數、每股價格、百分比單位與中英資料字典。財務資料仍在原本 `portfolio`、`snapshots` 等路徑，不另複製一組可被重複計算的餘額。匯入時核對格式及單位，再還原完整內容；資料字典不寫入 localStorage、不計入內容變更摘要。仍支援舊 JSON 結構 1／2／3。

預設持倉 CSV 在原十二欄後增加 `formatVersion,currency,quantityUnit,priceUnit,rateUnit,recordType`。接受完整欄位重排，拒絕重複／未知欄位、未知版本、非 TWD、張數單位、比例小數及混合實際／估計部位。CSV 的 `estimated_holdings` 匯入後維持待成交核對；匯入實際持倉也不會自行清除原本待核對狀態。只有表頭的空白持倉 CSV 不攜帶來源狀態，保留目的端狀態。CSV 仍只替換持倉；要完整保存時間、快照、商品資訊與現金，請用 JSON。

方案 CSV 另標示 `rebalance_plan_not_executed`、TWD 與股數單位，仍是尚未成交的試算報表，不能當成持倉匯入。其他系統須明確對應本專案欄位，不能因為支援 JSON／CSV 就宣稱可直接匯入。格式指南可從頁面下載，也可讀取 [財務欄位定義](public/data/finance-format-v1.json)。完整相容性與測試紀錄見 [財務交換建置紀錄](FINANCE_INTERCHANGE.md)。

## V4 4.2.0 資產佔比與清空重新填寫

總資產下方新增四類資產圓環與可展開明細：核心持股、台股正二、其他證券及現金（含 T+2）。依使用者選擇的分類，以股數乘輸入價格計算；正二不再乘二。分母為目前證券市值加現金及帶正負號的交割款，不含本次投入／提領。估計持倉明示待成交核對；負淨現金保留負數佔比、停止繪製圓環，零／負總資產及無效估值也不顯示誤導性的圖表。

「清空目前輸入」須在確認視窗輸入「清空」才能執行，並提供先匯出 JSON 的選項。重設目前持倉、現金、交割款、投入／提領、目標、情境與核對狀態；現金下限及容許偏差回到初始值。保留歷史快照、備份紀錄與其他版本資料，不清除整個 localStorage。取消／Escape 不變更內容；確認後一般模式自動保存、暫用模式不寫入；保存衝突或資料損壞導致保存停止時，禁止清空以免誤以為保存成功。已啟動但尚未完成的匯入在清空後失效。完整的初始空白狀態可保存與備份還原，交易試算仍要求有效且大於零的資產。

新增估值邊界單元測試與 `tests/v4_allocation_reset.py`，涵蓋分類調整、負現金、不完整輸入、四種視窗尺寸、清空確認、取消、備份恢復、快照保留、估計持倉、延遲匯入及跨分頁衝突；納入本機、CI 與正式站驗證。
